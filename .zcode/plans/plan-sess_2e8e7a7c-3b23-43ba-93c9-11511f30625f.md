# FIDSUS 少样本标签对比实验 — 实施计划

## 目标

为 FIDSUS 项目添加"针对样本较少标签"的实验能力，覆盖 5 个需求：FIDSUS / FedAvg / FIDSUS-no-fusion 三种方法在少数标签上的准确率与召回率；FIDSUS vs FIDSUS-no-fusion 收敛速度对比；测试；一键运行脚本；使用文档。

> 关键约束：当前设备无 GPU，**测试必须轻量**（少量客户端、少量轮次、合成小数据），仅验证代码可正常运行；运行脚本使用真实参数(100轮/两数据集)，用户后续在带 GPU 的机器上跑。

## 设计概览

### A. 新增"标签级指标"采集 (核心新增)

当前代码只记录总体加权 accuracy/auc。需要新增**每个标签的准确率(precision)和召回率(recall)**，尤其关注少数标签。

- 修改 `system/flcore/clients/clientbase.py`：在 `test_metrics()` 增加返回每标签的混淆统计(correct/total per label)，或新增方法 `test_metrics_per_label()`。
- 修改 `system/flcore/clients/clientFIDSUS.py`：同样为 `test_metrics_personalized()` 增加每标签统计。
- 在 `serverbase.py` / `FIDSUS.py` 的 `evaluate()` 中聚合所有客户端的每标签统计，计算每标签 precision/recall。
- 新增记录数组：`self.rs_test_acc_per_label`, `self.rs_test_recall_per_label`（每轮一个 list），保存进 h5 文件。

**少数标签定义**（按数据集全局样本量阈值自动选取）：
- NSLKDD: label 2 (87 样本) — 极少
- UNSW: label 8 (139), 4 (1210), 1 (1824), 2 (2154) — 较少

### B. 新增 FIDSUS-no-fusion 消融变体 (需求 3)

通过参数 `--use_fusion` (bool, 默认 True) 控制是否启用跨轮特征融合，避免复制整个类。

- 在 `clientFIDSUS.py` 的 `train()` 末尾：
  ```python
  if self.use_fusion:
      self.protos = aggregation(self.protos_g, self.protos_per)
  else:
      self.protos = self.protos_g   # 仅全局原型，不做 MMD 融合
  ```
- 在 `clientbase.py.__init__` 读取 `args.use_fusion`；`main.py` 增加参数；当 `use_fusion=False` 时 algorithm 名后缀为 `FIDSUS_no_fusion`（用于结果文件区分）。

### C. 收敛速度对比 (需求 4)

收敛速度 = 达到某准确率阈值所需轮次 + 收敛区域(rounds)的标准差。利用每轮记录的 `rs_test_acc`：
- 计算"达到 90% 最终最佳准确率的轮次"(收敛轮次)
- 计算"最后 10 轮准确率标准差"(稳定性)
- 在 runner 脚本中从 h5 文件读取并对比 FIDSUS vs FIDSUS_no_fusion，输出表格。

## 测试策略 (轻量，无 GPU 也能跑)

由于无 GPU，测试设计为 **CPU 可快速完成**：
- `conftest.py` 生成一个 `tests/_tmpdata/MINI/` 合成数据集：3 客户端 × 极少样本(每客户端 20-50 样本)，格式与真实 npz 一致。
- `test_client_server.py` 用 `-nc 3 -gr 2 -dev cpu` 跑完整流程，验证三种算法均能产出 h5 文件且每标签指标数组非空。
- 单元测试(metrics/models/data)纯逻辑，秒级完成。
- 用项目自带 `.venv` 的 python 运行，CPU 模式 torch 已可用(2.12.0+cpu)。

## 一键运行脚本设计

`system/run_all.py`（Python，跨平台，推荐 Windows 用）：
1. 定义实验矩阵：datasets=[NSLKDD, UNSW], algos=[FedAvg, FIDSUS, FIDSUS_no_fusion]
2. 对每个组合 subprocess 调用 `main.py`，传入 100 轮 + 正确 num_classes + rare labels
3. 运行后读取所有 h5，生成汇总表 `results/summary.csv` + 终端打印表格(各算法 × 各少数标签 precision/recall + 收敛轮次)

`run_experiments.sh`（bash 版，功能等价，供 Linux/WSL 用）。
